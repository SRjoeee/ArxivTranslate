用户体验地图（v1 草图期）
三个方向共用这一套信息架构；草图只比气质与密度
旅程 1 · 首次使用
打开 arXiv HTML 页 → 点图标
popup 默认引擎 Google 网页翻译（免费，零配置）→ 直接可点「翻译本页」
想要更好译文 → 引擎行显示「LLM · 未配置」→ 一键去设置页的引擎卡
改动：默认引擎从 LLM 改为免费引擎，首次点开就能用；目前默认 LLM 且没 key，第一眼是灰按钮
旅程 2 · 日常阅读
点图标 → 「翻译本页」（或快捷键）→ 看到哪翻到哪
读着切模式：上下 / 左右 / 仅译文，随时切
读完或想对照原文 → 「恢复原文」
popup 里只有这几件事；提示词、样式、术语全在设置页
旅程 3 · 出问题时
几块失败 → 页内失败块旁「重试」；popup 进度行给「重试 N 块」
key 失效 → 自动降级到免费引擎，popup 状态槽一条提示 + 「去修」
配置读不出 → 状态槽红条，说清「key 与引擎没生效」
所有提示走同一个「状态槽」，一次只显示最要紧的一条
Popup（320 宽）— 自上而下
1. 品牌 + 设置入口
2. 引擎行：名称 · 状态点（就绪 / 缺 key / 已降级）· 点开切引擎
3. 目标语言（源固定英文，不显示）
4. 主按钮：翻译本页 ⇄ 恢复原文
5. 模式分段：上下 / 左右 / 仅译文
6. 进度：已翻 / 已触发 · 失败 N → 重试
7. 状态槽（一次一条）
拿掉：后台连通行、块统计行、popup 里的提示词下拉
设置页 — 四个一级页，零深层
引擎：目标语言 · 三张引擎卡（选中的展开表单）· 测试连接 · 失败自动降级
阅读：默认模式 · 译文样式画廊（即选即预览）· 预翻译距离（滑杆）
提示词与术语：提示词列表 + 侧栏编辑器 · 术语表（仅 LLM 时出现在导航）
数据：缓存条数 / 体积 · 清空
即改即存；只有 LLM 端点表单要「应用」（申请 host 权限需要点击手势），测试连接测的是表单里的值
依赖 → 露出规则
非 arXiv 页 → popup 只剩一句话 + 设置入口
引擎 ≠ LLM → 提示词 / 术语 / 思考 / 降级开关不出现
离线引擎未下语言包 → 引擎卡内就有「下载」按钮（不再只在 popup）
未翻译 → 不显示进度 / 恢复 / 重试
样式 ≠ 自定义 → 不显示 CSS 框
窗口偏窄 → 左右选项加「将按上下显示」角标而非事后提示
