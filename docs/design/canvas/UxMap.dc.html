User experience map (v1 sketch stage)
All three directions share this information architecture; sketches compare only character and density
Journey 1 · First use
Open an arXiv HTML page → click the icon
Default popup engine Google web translation(free, no setup) → “Translate page” is immediately available
Want better translations → engine row shows “LLM · Not configured” → one click opens the engine card in settings
Change: default to the free engine instead of LLM for immediate first-use access; currently LLM is the default without a key, so users first see a disabled button
Journey 2 · Everyday reading
Click icon → “Translate page” (or shortcut) → translate as you read
Switch modes at any time while reading: stacked / side by side / translation only
Finished reading or want the source → “Restore original”
Only these actions belong in the popup; prompts, styles, and terminology live in settings
Journey 3 · When something goes wrong
Some blocks fail → “Retry” beside each failed block; popup progress row offers “Retry N blocks”
Key expires → automatically fall back to a free engine; one popup status notice + “Fix”
Config cannot be read → red status notice explaining that key and engine settings did not take effect
All notices share one status area, showing only the most important one at a time
Popup (320 wide) — top to bottom
1. Brand + settings entry
2. Engine row: name · status dot (ready / missing key / fallback active) · click to switch engines
3. Target language (source fixed to English, hidden)
4. Primary button: Translate page ⇄ Restore original
5. Mode segments: stacked / side by side / translation only
6. Progress: translated / triggered · N failed → retry
7. Status area (one notice at a time)
Remove: background-connectivity row, block-statistics row, popup prompt dropdown
Settings — four top-level pages, no nested pages
Engine: target language · three engine cards (selected card expands its form) · test connection · automatic fallback
Reading: default mode · translation-style gallery (preview on selection) · translate-ahead distance (slider)
Prompts & terms: prompt list + side editor · glossary (navigation entry appears only for LLM)
Data: cache entries / size · clear
Save on change; only the LLM endpoint form needs “Apply” (host permission requests require a click gesture); connection tests use form values
Dependencies → visibility rules
Non-arXiv page → popup shows only one sentence + settings entry
Engine ≠ LLM → hide prompts / glossary / thinking / fallback toggle
Offline engine without language pack → “Download” appears inside the engine card (not only in the popup)
Not translated → hide progress / restore / retry
Style ≠ custom → hide CSS field
Narrow window → badge the side-by-side option “Will use stacked layout” instead of explaining afterward
