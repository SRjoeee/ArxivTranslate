This project is released under GPL-3.0. The files below were ported from reference projects under the same licence (sources under `reference/`, git-ignored) and keep their origin together with a statement of modification, as GPL §5 requires. Each ported file carries the same origin line and date in its header — §5(a) wants the modification notice dated. One MIT source is listed with its own notice.
